# `right_click_block`

* **Categoría:** `Interacción` 
* **Identificador / Alias:** `RIGHT_CLICK_BLOCK`

---

Se dispara exclusivamente al hacer clic derecho sobre un bloque.
```yaml
triggers:
 - id: inspect_block
    type: RIGHT_CLICK_BLOCK
    effects:
 - type: MESSAGE
        message: "<gray>Has interactuado con un bloque."
```
