# `left_click`

* **Categoría:** `Interacción` 
* **Identificador / Alias:** `LEFT_CLICK`

---

Se dispara con clic izquierdo (ataque o golpe al aire).
```yaml
triggers:
 - id: sweep_blade
    type: LEFT_CLICK
    effects:
 - type: PLAY_SOUND
        sound: ENTITY_PLAYER_ATTACK_SWEEP
```
