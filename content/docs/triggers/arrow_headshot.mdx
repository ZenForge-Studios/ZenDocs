# `arrow_headshot`

* **Categoría:** `Proyectiles & Arquería` 
* **Identificador / Alias:** `arrow_headshot` 
* **Contexto Inyectado:** `EVENT`, `PROJECTILE`, `VICTIM`

---

Al impactar un disparo a la cabeza del oponente.

### Ejemplo de Configuración:
```yaml
effects:
 - id: play_sound
    args:
      sound: ENTITY_EXPERIENCE_ORB_PICKUP
      volume: 1.0
      pitch: 1.0
    triggers:
 - arrow_headshot
```
