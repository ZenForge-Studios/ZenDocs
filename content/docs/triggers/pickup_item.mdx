# `pickup_item`

* **Categoría:** `Nuevos Triggers de Eventos Adicionales` 
* **Identificador / Alias:** `PICKUP_ITEM`

---

Se dispara cuando el jugador recoge un ítem del suelo con el ítem equipado.
```yaml
triggers:
 - id: on_pickup
    type: PICKUP_ITEM
```
