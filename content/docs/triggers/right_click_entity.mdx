# `right_click_entity`

* **Categoría:** `Nuevos Triggers de Eventos Adicionales` 
* **Identificador / Alias:** `RIGHT_CLICK_ENTITY`

---

Se dispara al hacer clic derecho con el ítem sobre cualquier entidad viva.
```yaml
triggers:
 - id: inspect_entity
    type: RIGHT_CLICK_ENTITY
```
