# `block_break`

* **Categoría:** `Bloques` 
* **Identificador / Alias:** `BLOCK_BREAK`

---

Se dispara cuando el jugador destruye un bloque con la herramienta.
```yaml
triggers:
 - id: explosive_mining
    type: BLOCK_BREAK
    filters:
 - type: BLOCKS
        blocks: ["STONE", "DEEPSLATE"]
    effects:
 - type: EXPLOSION
        power: 1.5
        breakBlocks: true
```
