# `respawn`

* **Categoría:** `Jugador & Movimiento` 
* **Identificador / Alias:** `RESPAWN`

---

Se dispara inmediatamente después de que el jugador reaparece tras morir.
```yaml
triggers:
 - id: respawn_shield
    type: RESPAWN
    effects:
 - type: ADD_POTION_EFFECT
        effect: RESISTANCE
        duration: 100
        amplifier: 1
```
