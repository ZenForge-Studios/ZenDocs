# `swap_hands`

* **Categoría:** `Inventario` 
* **Identificador / Alias:** `SWAP_HANDS`

---

Se dispara cuando el jugador intercambia el ítem a la mano secundaria (tecla F).
```yaml
triggers:
 - id: swap_parry
    type: SWAP_HANDS
    effects:
 - type: ACTIONBAR
        message: "<yellow> Modo guardia activado"
```
