# `enchant_item`

* **Categoría:** `Nuevos Triggers de Eventos Adicionales` 
* **Identificador / Alias:** `ENCHANT_ITEM`

---

Se dispara cuando el ítem es encantado en una mesa de encantamientos.
```yaml
triggers:
 - id: enchant_surge
    type: ENCHANT_ITEM
```
