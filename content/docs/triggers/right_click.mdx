# `right_click`

* **Categoría:** `Interacción` 
* **Identificador / Alias:** `RIGHT_CLICK`

---

Se dispara con clic derecho con el ítem en la mano principal (al aire o contra bloque).
```yaml
triggers:
 - id: cast_spell
    type: RIGHT_CLICK
    cooldownSeconds: 3.0
    effects:
 - type: PROJECTILE_BEAM
        particle: FLAME
        distance: 12.0
        damage: 6.0
```
