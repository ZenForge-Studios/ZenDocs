# `consume`

* **Categoría:** `Estado del Ítem` 
* **Identificador / Alias:** `CONSUME`

---

Se dispara cuando el jugador termina de comer o beber un alimento o consumible.
```yaml
triggers:
 - id: divine_apple
    type: CONSUME
    effects:
 - type: SET_HEALTH
        amount: 20.0
 - type: ADD_POTION_EFFECT
        effect: REGENERATION
        amplifier: 2
        duration: 200
```
