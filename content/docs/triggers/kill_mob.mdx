# `kill_mob`

* **Categoría:** `Nuevos Triggers de Eventos Adicionales` 
* **Identificador / Alias:** `KILL_MOB`

---

Se dispara cuando el jugador mata a cualquier criatura que no sea un jugador.
```yaml
triggers:
 - id: on_mob_slay
    type: KILL_MOB
    effects:
 - type: LIFESTEAL
        percent: 25.0
```
