# `ping_below`

* **Categoría:** `Nuevas Condiciones de Armadura, Estado y Entorno` 
* **Identificador / Alias:** `PING_BELOW`

---

Comprueba que el ping de latencia de red del jugador sea menor al umbral configurado.
```yaml
conditions:
 - type: PING_BELOW
    ping: 80
```
