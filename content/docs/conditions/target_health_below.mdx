# `target_health_below`

* **Categoría:** `Nuevas Condiciones de Armadura, Estado y Entorno` 
* **Identificador / Alias:** `TARGET_HEALTH_BELOW`

---

Evalúa si la vida del objetivo es menor a un valor numérico específico.
```yaml
conditions:
 - type: TARGET_HEALTH_BELOW
    health: 12.0
```
