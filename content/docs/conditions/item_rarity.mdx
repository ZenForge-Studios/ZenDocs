# `item_rarity`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `ITEM_RARITY`

---

Verifica la rareza configurada en el ítem (`COMMON`, `RARE`, `EPIC`, `LEGENDARY`).
```yaml
conditions:
 - type: ITEM_RARITY
    rarity: LEGENDARY
```
