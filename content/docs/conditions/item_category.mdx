# `item_category`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `ITEM_CATEGORY`

---

Verifica la categoría asignada en la definición del ítem (`category: weapons`, etc.).
```yaml
conditions:
 - type: ITEM_CATEGORY
    category: swords
```
