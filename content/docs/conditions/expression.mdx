# `expression`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `EXPRESSION`

---

Evalúa una expresión matemática o lógica con variables dinámicas del contexto (`damage`, `health`, etc.).
```yaml
conditions:
 - type: EXPRESSION
    expression: "health < 10"
```
