# `permission`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `PERMISSION / HAS_PERMISSION`

---

Verifica si el jugador cuenta con un permiso específico en su gestor de permisos (LuckPerms).
```yaml
conditions:
 - type: PERMISSION
    permission: "zci.tier.vip"
```
