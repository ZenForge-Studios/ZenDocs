# `biome`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `BIOME`

---

Verifica si la ubicación coincide con un bioma específico.
```yaml
conditions:
 - type: BIOME
    biome: "DESERT"
```
