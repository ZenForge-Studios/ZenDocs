# `distance`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `DISTANCE`

---

Verifica la distancia euclidiana en bloques entre el jugador y el objetivo.
```yaml
conditions:
 - type: DISTANCE
    operator: "<="
    value: 8.0
```
