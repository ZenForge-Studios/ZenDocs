# `chance`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `CHANCE`

---

Determina una probabilidad entre `0.0` y `1.0` (o `0%` a `100%`).
```yaml
conditions:
 - type: CHANCE
    chance: 0.35 # 35% de probabilidad
```
