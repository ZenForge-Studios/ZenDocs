# `entity_type`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `ENTITY_TYPE / TARGET_TYPE`

---

Verifica el tipo de entidad involucrada como objetivo (e.g. `ZOMBIE`, `SKELETON`, `PLAYER`, `ENDER_DRAGON`).
```yaml
conditions:
 - type: ENTITY_TYPE
    type: ENDERMAN
```
