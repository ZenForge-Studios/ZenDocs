# `has_item`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `HAS_ITEM`

---

Comprueba si el inventario del jugador contiene cierta cantidad de un ítem.
```yaml
conditions:
 - type: HAS_ITEM
    material: DIAMOND
    amount: 3
```
