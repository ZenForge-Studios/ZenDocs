# `variable`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `VARIABLE`

---

Compara el valor de una variable persistente almacenada en la instancia del ítem.
```yaml
conditions:
 - type: VARIABLE
    variable: combo
    operator: ">="
    value: 5
```
