# `world_time`

* **Categoría:** ` Catálogo de Condiciones` 
* **Identificador / Alias:** `WORLD_TIME`

---

Verifica la hora del mundo en ticks (0 a 24000) o mediante el flag de noche.
```yaml
conditions:
 - type: WORLD_TIME
    night: true # Solo activo entre ticks 13000 y 23000
```
