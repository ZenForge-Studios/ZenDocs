# ZenContest

Bienvenido a la documentación oficial de **ZenContest**, el plugin de competencias y eventos periódicos de alto rendimiento para servidores **PaperMC (1.21+)**, desarrollado en **Kotlin 2.1+** con integración nativa a la suite **ZenSeries** a través de **ZenCore**.

---

## Descripción General

**ZenContest** es un sistema automatizado de torneos y competencias que replica e innova sobre las mecánicas de *Jacob's Farming Contest* de Hypixel Skyblock. Los jugadores compiten durante periodos determinados (por ejemplo, 20 minutos) recolectando objetivos específicos (cultivos, minerales, madera, peces o criaturas).

### Características Destacadas:
- **Adventure API Nativa:** Todo el sistema de textos utiliza etiquetas MiniMessage (`<gradient>`, `<gold>`, `<hover>`, etc.).
- **Zero-Database Block Tracker:** Al operar junto a **ZenCore**, los bloques colocados por jugadores se guardan en el `PersistentDataContainer` (PDC) de los Chunks, eliminando el lag por escrituras SQL continuas.
- **Sistema de Brackets Dinámicos:** Asignación de rangos (Diamante, Platino, Oro, Plata, Bronce) mediante percentiles de participantes o récords dinámicos (*Dynamic Benchmarks*).
- **Tienda de Medallas y Recompensas:** Interfaz gráfica integrada (`/contest shop`) para intercambiar medallas y tickets por premios especiales.
- **Scoreboards & BossBars Ultra-Optimizadas:** Dirty-checking para transmitir paquetes únicamente cuando los valores cambian, además de integración directa con **TAB**.
