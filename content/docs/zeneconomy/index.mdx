# ZenEconomy (v2.0)

Bienvenido a la documentación oficial de configuración y arquitectura de **ZenEconomy v2.0 (ZenCore Native)**.  
ZenEconomy es un motor de economía modular de alto rendimiento para servidores de Minecraft **Paper 1.21+ (Java 21)**, optimizado con persistencia asíncrona, pools dedicados HikariCP, comandos dinámicos por divisa, sistema de cheques físicos anti-dupe y auditoría de transacciones en tiempo real.
