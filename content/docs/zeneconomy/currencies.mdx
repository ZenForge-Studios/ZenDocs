# Configuración de Monedas (currencies/)

---

Cada archivo `.yml` dentro de `plugins/ZenEconomy/currencies/` representa una moneda completamente independiente. Puedes crear tantas monedas como requiera tu servidor (por ejemplo: `gems.yml`, `crystals.yml`, `coins.yml`, `tokens.yml`).

### Ejemplo Completo Explicado: `currencies/nexcoin.yml`

```yaml
id: nexcoin
name: "NexCoin"
name-singular: "NexCoin"
name-plural: "NexCoins"
symbol: "⛁"
color: "#9238c9"
prefix: ""
suffix: "<#9238c9>NexCoins</#9238c9>"

default: 0
max: -1                  # -1 = sin límite
payable: true
decimal: false
max-decimals: 0          # Máximo 4 decimales soportados

# Solo UNA moneda local puede tener vault: true (si usas EssentialsX/CMI déjalo en false)
vault: false

# Si es true, /nexcoin <jugador> funciona como atajo de /nexcoin bal <jugador>
balance-shorthand: false

format: "<#9238c9>%amount% %suffix%</#9238c9>"
format-short: "<#9238c9>%symbol% %amount%</#9238c9>"
decimal-format: "#,##0"
decimal-format-short: "#,##0"

commands:
  - nexcoin
  - nexcoins
  - nc

icon:
  material: "NETHER_STAR"
  custom-model-data: 0
  display-name: "<#9238c9><bold>NexCoins</bold></#9238c9>"
  lore:
    - "<gray>Moneda exclusiva del servidor."

# Casa de Cambio (Exchange)
exchange:
  enabled: true
  tax-percent: 2.5       # Comisión porcentual del intercambio (0.0 a 99.0)
  daily-limit: 5000.0    # Límite diario de gasto por jugador (-1 = sin límite)
  rates:
    gems: 0.5
    vault: 100.0

# Impuestos en pagos entre jugadores (/nexcoin pay)
tax:
  pay-percent: 5.0       # 5% de impuesto retenido al enviar pagos

# Límites por transacción en /pay
limits:
  min-pay: 1.0
  max-pay: 100000.0      # -1 = sin límite

# Cheques físicos (/nexcoin note <cantidad>)
notes:
  enabled: true

# Multiplicadores automáticos de ZenCore Boosters
boosters:
  enabled: true
```

<Callout type="tip">
Los comandos listados en `commands:` se registran dinámicamente en tiempo de ejecución. Los jugadores pueden consultar su balance, transferir dinero o crear cheques utilizando cualquiera de los alias asignados.
</Callout>
