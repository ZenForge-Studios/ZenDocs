# Estructura de Archivos

---

Al iniciar el servidor, ZenEconomy genera y administra la siguiente estructura en `plugins/ZenEconomy/`:

```
plugins/ZenEconomy/
├── config.yml              # Configuración principal, pool de base de datos, ledger y sincronización
├── messages.yml            # Mensajes del plugin en formato Adventure MiniMessage
├── zeneconomy.db           # Base de datos SQLite local (si storage.type es SQLITE)
└── currencies/             # Definición de cada moneda individual e independiente
    ├── crystals.yml        # Moneda de ejemplo (Cristales)
    ├── gems.yml            # Moneda de ejemplo (Gemas)
    └── nexcoin.yml         # Moneda avanzada con cheques, límites e impuestos
```
