# API para Desarrolladores (ZenEconomy v2.0)

---

Esta guía detalla cómo integrar **ZenEconomy v2.0** en tus plugins de Paper 1.21+ tanto mediante **`ZenEconomyAPI`** directa como de forma desacoplada a través de **`ZenCore` (`ZenEconomyProvider` & `ZenEngine`)**.

---

## Dependencia (Maven & Gradle)

### Maven (`pom.xml`)
```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependencies>
    <!-- Opcional si usas ZenCore directamente -->
    <dependency>
        <groupId>com.cuac_xd.zencore</groupId>
        <artifactId>zencore</artifactId>
        <version>1.0.0</version>
        <scope>provided</scope>
    </dependency>

    <dependency>
        <groupId>com.cuac_xd.zeneconomy</groupId>
        <artifactId>ZenEconomy</artifactId>
        <version>2.0.0</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
```

### Gradle (Kotlin DSL - `build.gradle.kts`)
```kotlin
repositories {
    mavenCentral()
    mavenLocal()
    maven("https://jitpack.io")
}

dependencies {
    compileOnly("com.cuac_xd.zencore:zencore:1.0.0")
    compileOnly("com.cuac_xd.zeneconomy:ZenEconomy:2.0.0")
}
```

```yaml
name: MiPlugin
version: 1.0.0
```

## Opción A: Uso Desacoplado vía ZenCore (Recomendado)

Si tu plugin ya depende de **ZenCore**, no necesitas importar `ZenEconomy` como dependencia directa. ZenEconomy registra un `ZenEconomyProvider` tipado en `ZenCoreAPI.economy`:

```java
import com.cuac_xd.zencore.api.ZenCoreAPI;
import com.cuac_xd.zencore.hooks.ZenHooksHub;

// Consultar o cobrar cualquier moneda (Vault o ZenEconomy) de forma segura:
if (ZenHooksHub.hasAny(player, "gems", 50.0)) {
    boolean paid = ZenHooksHub.withdrawAny(player, "gems", 50.0);
    if (paid) {
        player.sendMessage("¡Compra completada!");
    }
}

// Operaciones asíncronas directas sobre ZenEconomyProvider:
ZenCoreAPI.getEconomy().depositAsync(player.getUniqueId(), "crystals", 100.0)
        .thenAccept(ok -> { /* callback */ });

// Repartir recompensa a toda la party del jugador:
ZenHooksHub.depositPartyAny(partyId, "gems", 200.0, true);
```

### Condiciones y Efectos Nativos en YAML
ZenEconomy registra automáticamente las siguientes reglas para `ZenEngine`:
* **Condiciones**:
  * `has_currency` — args: `{ currency: "gems", amount: 50 }`
  * `currency_balance_above` — args: `{ currency: "crystals", amount: 1000 }`
* **Efectos**:
  * `give_currency` — args: `{ currency: "gems", amount: 25, boosted: true }` *(aplica boosters si `boosted: true`)*
  * `take_currency` — args: `{ currency: "gems", amount: 10 }`
  * `exchange_currency` — args: `{ from: "crystals", to: "gems", amount: 100 }`

## Opción B: Uso Directo de `ZenEconomyAPI`

### 1. Obtener la Instancia
```java
import com.cuac_xd.zeneconomy.api.ZenEconomyAPI;

ZenEconomyAPI api = ZenEconomyAPI.get();
```

### 2. Operaciones Síncronas (Fast-Path en Caché)
```java
// Consultar saldo (acepta Player, OfflinePlayer o UUID)
double balance = api.getBalanceSync(player, "nexcoin");

// Comprobar y retirar
if (api.hasSync(player, "nexcoin", 100.0)) {
    boolean withdrawn = api.withdrawSync(player.getUniqueId(), "nexcoin", 100.0);
}

// Depósito y set síncrono
api.depositSync(player.getUniqueId(), "nexcoin", 50.0);
api.setBalanceSync(player.getUniqueId(), "nexcoin", 1000.0);
```

### 3. Operaciones Asíncronas
```java
UUID uuid = player.getUniqueId();

api.getBalance(uuid, "nexcoin").thenAccept(bal -> { /* ... */ });
api.deposit(uuid, "nexcoin", 100.0).thenAccept(ok -> { /* ... */ });
api.withdraw(uuid, "nexcoin", 25.0).thenAccept(ok -> { /* ... */ });
api.transfer(senderUuid, receiverUuid, "nexcoin", 50.0).thenAccept(ok -> { /* ... */ });
```

### 4. Depositar Recompensas con Boosters de ZenCore
```java
api.depositWithBoosters(uuid, "gems", 50.0, "quest-reward").thenAccept(finalAmount -> {
    if (finalAmount > 0) {
        player.sendMessage("¡Recibiste " + api.format("gems", finalAmount) + " (con boosters)!");
    }
});
```

### 5. Evento de Transacciones (`EconomyTransactionEvent`)
Se dispara **antes** de aplicar cualquier cambio y es 100% cancelable. Tipos: `DEPOSIT`, `WITHDRAW`, `SET`, `TRANSFER`, `EXCHANGE`, `NOTE_CREATE`, `NOTE_REDEEM`, `TAX`, `MIGRATION`.

```java
import com.cuac_xd.zeneconomy.api.events.EconomyTransactionEvent;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;

public class TransactionListener implements Listener {

    @EventHandler
    public void onTransaction(EconomyTransactionEvent event) {
        UUID uuid = event.getPlayerUuid();
        String currency = event.getCurrencyId();
        double amount = event.getAmount();

        // Cancelar si la transacción no cumple reglas del servidor:
        // event.setCancelled(true);
    }
}
```
