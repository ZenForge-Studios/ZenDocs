# Requisitos del Sistema

---

Para asegurar el rendimiento óptimo y el funcionamiento correcto de **ZenEconomy v2.0**, tu servidor debe cumplir con los siguientes requisitos:

- **Plataforma**: Servidor Paper, Purpur o forks derivados en versión **1.21 o superior**.
- **Java**: **Java 21** o superior (requerido por Paper 1.21 y características modernas de concurrencia).
- **Dependencia Obligatoria**: **ZenCore** (`ZenCore-1.0.0.jar` o superior) para pools de conexiones `ZenDatabaseEngine`, interfaz de menús `ZenMenu`, protecciones `ZenProtectionHub`, sincronización multi-servidor y compatibilidad con `ZenBoosterEngine`.
- **Dependencias Opcionales**:
  - `PlaceholderAPI`: Para mostrar saldos y rankings en Scoreboards, TAB, chat y menús externos.
  - `Vault`: Requerido si deseas conectar la economía clásica con ZenEconomy (mediante `vault: true` en una divisa o usando el puente bidireccional con EssentialsX/CMI).
