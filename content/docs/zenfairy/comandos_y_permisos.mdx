# Comandos y Permisos

---

El comando principal es `/zenfairy` (con los alias `/zf` y `/souls`), registrado dinámicamente mediante `ZenCommand`.

| Comando | Permiso | Descripción |
| :--- | :--- | :--- |
| `/zf` | `zenfairy.command.use` | Muestra la ayuda de comandos según los permisos del usuario. |
| `/zf menu [tipo]` | `zenfairy.command.use` | Abre el menú de canjes e hitos (por defecto: `fairy`). |
| `/zf hint [tipo]` | `zenfairy.command.use` | Muestra distancia aproximada (±5 bloques), dirección cardinal y zona del alma sin encontrar más cercana. |
| `/zf top [tipo]` | `zenfairy.command.use` | Muestra el Top 10 de exploradores desde la caché en memoria. |
| `/zf set <tipo> [zona]` | `zenfairy.admin` | Marca el bloque mirado como alma y le asigna una zona (default: `default`). |
| `/zf remove` | `zenfairy.admin` | Elimina el alma del bloque mirado. |
| `/zf wand <tipo> [zona]` | `zenfairy.admin` | Entrega la **Varita de Edición Administrativa** (PDC). |
| `/zf location [tipo]` | `zenfairy.admin` | Abre el menú interactivo de ubicaciones con teletransporte seguro. |
| `/zf reset <jugador> <tipo>` | `zenfairy.admin.reset` | Resetea progreso, almas gastadas e hitos de un jugador (asíncrono, online u offline). |
| `/zf reload` | `zenfairy.admin` | Recarga configuraciones, tipos de almas, hologramas y rankings. |

---

### Controles de la Varita de Edición (`/zf wand <tipo> [zona]`)

La varita de edición permite configurar almas sobre el terreno sin necesidad de escribir comandos repetitivos:

- **Clic Derecho en bloque**: Coloca un alma con el tipo y zona configurados en la varita.
- **Shift + Clic Izquierdo en bloque**: Elimina el alma de dicho bloque.
- **Shift + Clic Derecho al aire**: Emite partículas brillantes en todas las almas colocadas dentro de 3 chunks a la redonda para ubicarlas rápidamente.
