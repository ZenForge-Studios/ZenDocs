# Configuración (config.yml)

---

`config.yml` es gestionado automáticamente por **`ZenConfig`**: al actualizar el plugin, cualquier clave nueva se inyecta sin sobrescribir tus personalizaciones existentes.

```yaml
messages:
  prefix: "<gradient:#ff70a6:#ff9770><bold>ZenFairy</bold></gradient> <dark_gray>» </dark_gray>"
  reload: "<green>Configurations successfully reloaded.</green>"
  no-permission: "<red>You don’t have permission to run this command.</red>"
  player-only: "<red>This command can only be executed by a player.</red>"

  # Mensajes de comandos
  unknown-command: "<red>Unknown command. Use /zf to see help.</red>"
  invalid-soul-type: "<red>The soul type '<yellow>{soul_type}</yellow>' does not exist.</red>"
  set-usage: "<red>Usage: /zf set <soul_type> [zone]</red>"
  reset-usage: "<red>Usage: /zf reset <player> <soul_type></red>"
  player-not-found: "<red>The player <yellow>{player}</yellow> was not found or has never played on the server.</red>"
  data-reset-success: "<green>The data of <yellow>{player}</yellow> for the soul type <yellow>{soul_type}</yellow> has been reset.</green>"
  wand-given: "<green>Received Admin Edit Wand for <yellow>{soul_type}</yellow> (zone: <aqua>{zone}</aqua>).</green>"

  # Interacción y protección de almas
  soul-already-exists: "<red>There is already a soul in this block. Use /zf remove first.</red>"
  look-at-block: "<red>You must be looking at a block.</red>"
  soul-found: "<green>You have found a {soul_display_name}<green>! <gray>({found}/{total})</gray></green>"
  soul-already-found: "<red>You had already found this soul.</red>"
  soul-set: "<green>You have placed a soul of type <yellow>{soul_type}</yellow> on the block you are looking at.</green>"
  soul-remove: "<green>You have removed the soul you were looking at.</green>"
  soul-not-found-at-loc: "<red>There is no soul on the block you are looking at.</red>"
  soul-protected-admin: "<yellow>Este bloque contiene un alma (<aqua>{soul_type}</aqua>). Usa Shift + Romper en Creativo o /zf remove.</yellow>"

  # Sistema de pistas (/zf hint)
  hint-found: "<aqua>Un {soul_display_name} <aqua>sin descubrir resuena aprox. a <yellow>{distance} bloques</yellow> hacia el <gold>{direction}</gold> (zona: <white>{zone}</white>).</aqua>"
  hint-none-remaining: "<green>¡Ya has encontrado todos los {soul_display_name} <green>de este mundo!</green>"

  # Mensajes de GUI
  no-menu-configured: "<red>This soul type doesn’t have a configured menu.</red>"
  not-enough-souls: "<red>You don’t have enough souls available.</red>"
  milestone-already-claimed: "<yellow>You have already claimed this milestone reward.</yellow>"
  conditions-not-met: "<red>You do not meet the required conditions for this reward.</red>"
  teleporting-to-soul: "<green>Teleporting to the soul’s location...</green>"

  help-message:
    - "<gradient:#ff70a6:#ff9770><bold>ZenFairy</bold></gradient> <gray>- Commands:</gray>"
    - "<light_purple>/zf menu [type]</light_purple> <gray>- Opens the soul menu.</gray>"
    - "<light_purple>/zf hint [type]</light_purple> <gray>- Gets a directional hint to the nearest soul.</gray>"
    - "<light_purple>/zf top [type]</light_purple> <gray>- Shows the top soul explorers.</gray>"
  admin-help-message:
    - "<light_purple>/zf reload</light_purple> <gray>- Reloads the configuration.</gray>"
    - "<light_purple>/zf set <type> [zone]</light_purple> <gray>- Marks the block you are looking at as a soul.</gray>"
    - "<light_purple>/zf remove</light_purple> <gray>- Unmarks the soul you are looking at.</gray>"
    - "<light_purple>/zf wand <type> [zone]</light_purple> <gray>- Gives the Admin Edit Wand.</gray>"
    - "<light_purple>/zf location <type></light_purple> <gray>- Displays the soul locations.</gray>"
    - "<light_purple>/zf reset <player> <type></light_purple> <gray>- Resets a player’s data.</gray>"

# Intervalo de actualización asíncrona de los rankings en memoria (mínimo 10s)
leaderboard:
  refresh-seconds: 60

# Menú paginado de ubicaciones (/zf location <tipo>)
locations-menu:
  title: "<dark_purple>Ubicaciones de Almas</dark_purple>"
  rows: 6
  items-per-page: 45

# Base de datos gestionada por ZenDatabaseEngine
database:
  type: SQLITE          # SQLITE o MYSQL
  sqlite:
    file: "zenfairy.db"
```
