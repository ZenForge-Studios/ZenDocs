# ZenFairy (v2.0 - ZenSeries Edition)

**ZenFairy** es un plugin avanzado para servidores Minecraft (**Paper / Purpur 1.21+**) desarrollado en Kotlin sobre la infraestructura de **ZenCore**. Permite la creación y recolección de **Almas Personalizables (Souls)** con soporte nativo de Adventure API, formato MiniMessage, menús interactivos sin parpadeos (`ZenMenu`), hologramas `TextDisplay` sin ArmorStands (`ZenHologramEngine`), radar de proximidad inmersivo, varita administrativa con PDC y sincronización de party (`ZenPartys`).
