# Configuración de Almas (`souls/<tipo>.yml`)

---

Cada archivo `.yml` dentro de `plugins/ZenFairy/souls/` define un tipo de alma independiente. El nombre del archivo determina su ID (ej: `dragon.yml` → ID `dragon`).

### Estructura Completa

```yaml
display-name: '<gradient:#da22ff:#9733ee>Fairy Soul</gradient>'

# Sonidos configurables (respetan volume y pitch; soportan enums Bukkit y Resource Packs namespace:key)
soul-found-sound:
  enabled: true
  sound: ENTITY_EXPERIENCE_ORB_PICKUP
  volume: 0.6
  pitch: 1.2
soul-already-found-sound:
  enabled: true
  sound: BLOCK_ANVIL_DESTROY
  volume: 0.3
  pitch: 1.0
all-souls-found-sound:
  enabled: true
  sound: ENTITY_PLAYER_LEVELUP
  volume: 0.8
  pitch: 1.0

# Partícula al encontrar el alma
found-soul-particle: WITCH

# Acciones por evento
first-soul-found-actions:
  - '[ZEN-ECO] vault 50000'
soul-found-actions:
  - '[ZEN-ECO] vault 3000'
all-souls-found-actions:
  - '[ZEN-ECO] vault 10000'
  - '[BROADCAST] <gold>%player%</gold> <green>ha encontrado todas las Fairy Souls!</green>'
  - '[SOUND] UI_TOAST_CHALLENGE_COMPLETE 1.0 1.0'

# Efectos nativos opcionales de ZenCore ZenEngine
soul-found-effects: []
all-souls-found-effects: []

# Animación fluida con ItemDisplay nativo de 1.21 (interpolación en cliente, isPersistent = false)
found-soul-animation:
  enabled: true
  texture: "eyJ0ZXh0dXJlcyI6..."
  duration: 40
  spin-speed: 10
  rise-speed: 0.05

# Holograma flotante opcional sobre cada alma (ZenHologramEngine - TextDisplay)
hologram:
  enabled: false
  y-offset: 1.35
  lines:
    - '{soul_display_name}'
    - '<gray>Zona: <aqua>{zone}</aqua></gray>'

# Notificación a compañeros cercanos de Party (requiere ZenPartys)
party-share:
  enabled: true
  radius: 32.0
  notify-members: true

# Indicadores de proximidad con efecto Radar (más rápido y pitch más agudo al acercarse)
indicators:
  visual:
    enabled: true
    particle: HAPPY_VILLAGER
    amount: 5
    interval-ticks: 40
    radius: 15.0
  auditory:
    enabled: true
    sound: BLOCK_NOTE_BLOCK_CHIME
    volume: 0.5
    pitch: 1.0
    interval-ticks: 60
    radius: 10.0

# Menú interactivo (ZenMenu) con refresco in-place sin parpadeos
menu:
  title: '<gradient:#da22ff:#9733ee>Fairy Souls</gradient>'
  rows: 6
  filler:
    material: GRAY_STAINED_GLASS_PANE
    name: ' '
  items:
    # Modo 1: Canje (gasta almas disponibles)
    soul_exchange:
      display-name: '<green>Canjear 5 Almas</green>'
      material: PLAYER_HEAD
      texture: "eyJ0ZXh0dXJlcyI6..."
      slot: 21
      souls-required: 5
      available-lore:
        - '<gray>Disponibles: <yellow>{souls_available}</yellow>/<dark_purple>{souls_required}</dark_purple>'
        - '<yellow>▶ Click para canjear'
      unavailable-lore:
        - '<gray>Disponibles: <yellow>{souls_available}</yellow>/<dark_purple>{souls_required}</dark_purple>'
        - '<red>✖ Almas insuficientes'
      actions:
        - '[ZEN-ECO] vault 10000'
        - '[ZEN-STAT] max_health 2'
        - '[SOUND] ENTITY_PLAYER_LEVELUP 1.0 1.2'

    # Modo 2: Milestone / Hito acumulativo (NO gasta almas, reclamable 1 sola vez)
    milestone_10:
      display-name: '<gold><bold>Hito: 10 Almas</bold></gold>'
      material: NETHER_STAR
      slot: 23
      milestone-required: 10
      one-time: true
      available-lore:
        - '<gray>Encontradas: <yellow>{souls_found}</yellow>/<gold>{souls_required}</gold>'
        - '<green>▶ Click para reclamar'
      unavailable-lore:
        - '<gray>Encontradas: <yellow>{souls_found}</yellow>/<gold>{souls_required}</gold>'
        - '<red>✖ Bloqueado'
      claimed-lore:
        - '<green>✔ Ya reclamado'
      actions:
        - '[ZEN-ECO] vault 25000'
```
