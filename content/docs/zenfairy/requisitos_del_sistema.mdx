# Requisitos del Sistema

---

- **Plataforma**: Servidor Paper, Purpur o forks derivados en versión **1.21 o superior**.
- **Java**: **Java 21** o superior.
- **Dependencia Obligatoria**: **ZenCore** (`ZenCore-1.0.0.jar` o superior) para pools de base de datos `ZenDatabaseEngine`, menús interactivos `ZenMenu`, hologramas nativos `ZenHologramEngine`, stats `ZenStatEngine` y protecciones `ZenProtectionHub`.
- **Dependencias Opcionales**:
  - `PlaceholderAPI`: Para placeholders de almas en Scoreboards, TAB y menús.
  - `Vault` / `ZenEconomy`: Para recompensas monetarias automáticas al encontrar almas o completar hitos.
  - `ZenPartys`: Para compartir y notificar hallazgos de almas entre miembros cercanos del grupo.
