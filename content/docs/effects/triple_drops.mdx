# `triple_drops`

* **Categorías:** `mining, drops` 
* **Identificador / Alias:** `triple_drops`

---

Triplica los drops conseguidos del bloque o criatura.
- **Categorías:** `mining, drops`
- **Requisitos de Trigger:** `mine_block, kill_entity`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `chance` | Probabilidad de triplicar botín (0 a 100). | `EXPRESSION` | `10` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: triple_drops
    args:
      chance: 1.0
```
