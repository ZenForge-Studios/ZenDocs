# `reflect_damage`

* **Categorías:** `combat, defense` 
* **Identificador / Alias:** `reflect_damage`

---

Devuelve un porcentaje del daño recibido directamente al atacante.
- **Categorías:** `combat, defense`
- **Requisitos de Trigger:** `EVENT`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `percentage` | Porcentaje de daño reflejado al atacante. | `EXPRESSION` | `0.2` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: reflect_damage
    args:
      percentage: 1.0
```
