# `bleed`

* **Categorías:** `combat, damage` 
* **Identificador / Alias:** `bleed`

---

Aplica daño sangrado por pulsos periódicos de tiempo con partículas de sangre.
- **Categorías:** `combat, damage`
- **Requisitos de Trigger:** `VICTIM o PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `ticks` | Cantidad de pulsos de sangrado. | `INTEGER` | `5` |
| `damage` | Daño por pulso. | `EXPRESSION` | `1.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: bleed
    args:
      ticks: 2
      damage: 1.0
```
