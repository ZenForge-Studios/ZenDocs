# `teleport`

* **Categorías:** `movement, teleport` 
* **Identificador / Alias:** `teleport`

---

Teletransporta a una entidad hacia una coordenada o destino.
- **Categorías:** `movement, teleport`
- **Requisitos de Trigger:** `PLAYER o VICTIM`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `target` | Entidad a transportar (player o victim). | `STRING` | `player` |
| `destination` | Destino (victim, player, spawn). | `STRING` | `victim` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: teleport
    args:
      target: SPEED
      destination: SPEED
```
