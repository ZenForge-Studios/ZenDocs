# `add_armor_toughness`

* **Categorías:** `attributes, defense` 
* **Identificador / Alias:** `add_armor_toughness`

---

Incrementa la dureza de la armadura frente a impactos pesados.
- **Categorías:** `attributes, defense`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Dureza de armadura extra. | `DECIMAL` | `1.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: add_armor_toughness
    args:
      amount: 1.0
```
