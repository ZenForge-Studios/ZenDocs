# `levitate_area`

* **Categorías:** `physics, area` 
* **Identificador / Alias:** `levitate_area`

---

Hace levitar temporalmente a todos los mobs y jugadores cercanos.
- **Categorías:** `physics, area`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `radius` | Radio del efecto. | `DECIMAL` | `4.0` |
| `duration` | Segundos de levitación. | `INTEGER` | `3` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: levitate_area
    args:
      radius: 1.0
      duration: 2
```
