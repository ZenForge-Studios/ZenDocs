# `vampirism`

* **Categorías:** `combat, player` 
* **Identificador / Alias:** `vampirism`

---

Restaura una cantidad plana de corazones al asestar golpes críticos.
- **Categorías:** `combat, player`
- **Requisitos de Trigger:** `EVENT`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Cantidad fija de corazones restaurados al asestar golpes. | `EXPRESSION` | `2.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: vampirism
    args:
      amount: 1.0
```
