# `auto_smelt`

* **Categorías:** `mining, drops` 
* **Identificador / Alias:** `auto_smelt`

---

Funde y cocina automáticamente los minerales y alimentos conseguidos.
- **Categorías:** `mining, drops`
- **Requisitos de Trigger:** `mine_block, kill_entity`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `give_exp` | Otorga la experiencia correspondiente por cocinar. | `BOOLEAN` | `true` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: auto_smelt
    args:
      give_exp: true
```
