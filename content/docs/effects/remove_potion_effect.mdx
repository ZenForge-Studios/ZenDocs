# `remove_potion_effect`

* **Categorías:** `potions, entity` 
* **Identificador / Alias:** `remove_potion_effect`

---

Remueve una poción determinada o purga todas las activas.
- **Categorías:** `potions, entity`
- **Requisitos de Trigger:** `PLAYER o VICTIM`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `effect` | Nombre de la poción o ALL para todas. | `STRING` | `ALL` |
| `target` | Objetivo afectado (player o victim). | `STRING` | `player` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: remove_potion_effect
    args:
      effect: SPEED
      target: SPEED
```
