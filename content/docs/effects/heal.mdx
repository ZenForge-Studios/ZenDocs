# `heal`

* **Categorías:** `player, entity, combat` 
* **Identificador / Alias:** `heal`

---

Restaura puntos de vida a la entidad objetivo.
- **Categorías:** `player, entity, combat`
- **Requisitos de Trigger:** `PLAYER o VICTIM`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Puntos de vida a curar (2 = 1 corazón). | `EXPRESSION` | `Obligatorio` |
| `target` | Entidad a curar (player o victim). | `STRING` | `player` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: heal
    args:
      amount: 1.0
      target: SPEED
```
