# `add_armor`

* **Categorías:** `attributes, defense` 
* **Identificador / Alias:** `add_armor`

---

Suma puntos planos a la barra de armadura.
- **Categorías:** `attributes, defense`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Puntos sumados a la barra de armadura. | `DECIMAL` | `2.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: add_armor
    args:
      amount: 1.0
```
