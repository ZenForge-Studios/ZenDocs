# `kill_nearby_monsters`

* **Categorías:** `combat, entity` 
* **Identificador / Alias:** `kill_nearby_monsters`

---

Elimina a todos los monstruos de bajo rango en el radio.
- **Categorías:** `combat, entity`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `radius` | Radio de aniquilación. | `DECIMAL` | `5.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: kill_nearby_monsters
    args:
      radius: 1.0
```
