# `add_movement_speed`

* **Categorías:** `attributes, movement` 
* **Identificador / Alias:** `add_movement_speed`

---

Otorga velocidad de desplazamiento base al jugador.
- **Categorías:** `attributes, movement`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Velocidad de movimiento adicional. | `DECIMAL` | `0.02` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: add_movement_speed
    args:
      amount: 1.0
```
