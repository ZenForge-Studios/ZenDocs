# `fill_bucket`

* **Categorías:** `utility, inventory` 
* **Identificador / Alias:** `fill_bucket`

---

Llena un cubo vacío con agua, lava o leche.
- **Categorías:** `utility, inventory`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `bucket_type` | Cubo lleno resultante (WATER_BUCKET, LAVA_BUCKET). | `MATERIAL` | `WATER_BUCKET` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: fill_bucket
    args:
      bucket_type: SPEED
```
