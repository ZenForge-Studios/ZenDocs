# `extinguish_fire_area`

* **Categorías:** `world, blocks` 
* **Identificador / Alias:** `extinguish_fire_area`

---

Extingue todas las llamás del suelo en un área determinada.
- **Categorías:** `world, blocks`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `radius` | Radio de extinción en bloques. | `INTEGER` | `4` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: extinguish_fire_area
    args:
      radius: 2
```
