# `lightning`

* **Categorías:** `world, combat` 
* **Identificador / Alias:** `lightning`

---

Invoca la caída de un rayo en la ubicación especificada.
- **Categorías:** `world, combat`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `effect_only` | Si es true, solo genera el efecto visual y sonoro sin causar fuego ni daño. | `BOOLEAN` | `false` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: lightning
    args:
      effect_only: true
```
