# `clone_target`

* **Categorías:** `entity, magic` 
* **Identificador / Alias:** `clone_target`

---

Crea un clon ilusorio del objetivo para distraer en combate.
- **Categorías:** `entity, magic`
- **Requisitos de Trigger:** `VICTIM`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `duration` | Segundos de duración del clon. | `INTEGER` | `8` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: clone_target
    args:
      duration: 2
```
