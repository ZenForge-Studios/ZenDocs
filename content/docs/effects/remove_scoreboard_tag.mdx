# `remove_scoreboard_tag`

* **Categorías:** `entity, tags` 
* **Identificador / Alias:** `remove_scoreboard_tag`

---

Elimina una etiqueta del Scoreboard de la entidad.
- **Categorías:** `entity, tags`
- **Requisitos de Trigger:** `VICTIM o PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `tag` | Etiqueta a eliminar. | `STRING` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: remove_scoreboard_tag
    args:
      tag: SPEED
```
