# `launch`

* **Categorías:** `combat, physics` 
* **Identificador / Alias:** `launch`

---

Propulsa a la entidad directamente por los aires.
- **Categorías:** `combat, physics`
- **Requisitos de Trigger:** `VICTIM o PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `y` | Fuerza de elevación vertical. | `EXPRESSION` | `1.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: launch
    args:
      y: 1.0
```
