# `run_player_command`

* **Categorías:** `player, commands` 
* **Identificador / Alias:** `run_player_command`

---

Obliga al jugador a ejecutar un comando como si lo escribiera.
- **Categorías:** `player, commands`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `command` | Comando ejecutado por el jugador. | `STRING` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: run_player_command
    args:
      command: SPEED
```
