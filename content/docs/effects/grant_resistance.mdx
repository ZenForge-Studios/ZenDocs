# `grant_resistance`

* **Categorías:** `potions, defense` 
* **Identificador / Alias:** `grant_resistance`

---

Aplica el efecto de poción de Resistencia reduciendo todo daño recibido.
- **Categorías:** `potions, defense`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `duration` | Duración en segundos. | `EXPRESSION` | `5` |
| `amplifier` | Nivel de resistencia. | `EXPRESSION` | `0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: grant_resistance
    args:
      duration: 1.0
      amplifier: 1.0
```
