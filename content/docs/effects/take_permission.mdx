# `take_permission`

* **Categorías:** `permissions, player` 
* **Identificador / Alias:** `take_permission`

---

Revoca un permiso otorgado al jugador.
- **Categorías:** `permissions, player`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `permission` | Nodo de permiso a revocar. | `STRING` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: take_permission
    args:
      permission: SPEED
```
