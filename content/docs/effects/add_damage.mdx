# `add_damage`

* **Categorías:** `combat, damage` 
* **Identificador / Alias:** `add_damage`

---

Agrega daño adicional al ataque en curso mediante fórmulas matemáticas.
- **Categorías:** `combat, damage`
- **Requisitos de Trigger:** `EVENT`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `damage` | Cantidad de daño adicional a sumar al evento. Soporta expresiones matemáticas. | `EXPRESSION` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `LATE` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: add_damage
    args:
      damage: 1.0
```
