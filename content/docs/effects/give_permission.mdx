# `give_permission`

* **Categorías:** `permissions, player` 
* **Identificador / Alias:** `give_permission`

---

Concede temporalmente un permiso de LuckPerms.
- **Categorías:** `permissions, player`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `permission` | Nodo de permiso de LuckPerms. | `STRING` | `Obligatorio` |
| `duration` | Segundos de duración temporal. | `INTEGER` | `60` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: give_permission
    args:
      permission: SPEED
      duration: 2
```
