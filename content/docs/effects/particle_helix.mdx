# `particle_helix`

* **Categorías:** `visual, particles` 
* **Identificador / Alias:** `particle_helix`

---

Genera una espiral ascendente de partículas rodeando a la entidad.
- **Categorías:** `visual, particles`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `particle` | Tipo de partícula. | `PARTICLE` | `PORTAL` |
| `radius` | Radio de giro. | `DECIMAL` | `1.0` |
| `height` | Altura total de la espiral. | `DECIMAL` | `2.5` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: particle_helix
    args:
      particle: SPEED
      radius: 1.0
      height: 1.0
```
