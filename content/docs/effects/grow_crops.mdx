# `grow_crops`

* **Categorías:** `farming, blocks` 
* **Identificador / Alias:** `grow_crops`

---

Acelera el crecimiento de cultivos simulando polvo de hueso.
- **Categorías:** `farming, blocks`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `radius` | Radio de maduración de cultivos. | `INTEGER` | `3` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: grow_crops
    args:
      radius: 2
```
