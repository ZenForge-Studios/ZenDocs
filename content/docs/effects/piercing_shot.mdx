# `piercing_shot`

* **Categorías:** `projectile, combat` 
* **Identificador / Alias:** `piercing_shot`

---

Permite a la flecha perforar múltiples entidades consecutivas.
- **Categorías:** `projectile, combat`
- **Requisitos de Trigger:** `PROJECTILE`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `pierce_count` | Número de entidades que atraviesa. | `INTEGER` | `3` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: piercing_shot
    args:
      pierce_count: 2
```
