# `take_money`

* **Categorías:** `economy, player` 
* **Identificador / Alias:** `take_money`

---

Deduce dinero de la cuenta de Vault como coste de habilidad.
- **Categorías:** `economy, player`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Cantidad de dinero a deducir. | `EXPRESSION` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: take_money
    args:
      amount: 1.0
```
