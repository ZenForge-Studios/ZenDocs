# `armor_pierce`

* **Categorías:** `combat, damage` 
* **Identificador / Alias:** `armor_pierce`

---

Ignora un porcentaje de la armadura y protección del objetivo atacado.
- **Categorías:** `combat, damage`
- **Requisitos de Trigger:** `EVENT`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `percentage` | Porcentaje de protección ignorado (0.3 = 30%). | `EXPRESSION` | `0.25` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `LATE` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: armor_pierce
    args:
      percentage: 1.0
```
