# `explosion`

* **Categorías:** `world, combat` 
* **Identificador / Alias:** `explosion`

---

Detona una explosión de potencia personalizada con control de bloques.
- **Categorías:** `world, combat`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `power` | Potencia de la explosión (2 = Creeper, 4 = TNT). | `EXPRESSION` | `2.0` |
| `break_blocks` | Si destruye bloques del entorno. | `BOOLEAN` | `false` |
| `set_fire` | Si deja fuego en el suelo. | `BOOLEAN` | `false` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: explosion
    args:
      power: 1.0
      break_blocks: true
      set_fire: true
```
