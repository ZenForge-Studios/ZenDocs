# `stop_sound`

* **Categorías:** `audio` 
* **Identificador / Alias:** `stop_sound`

---

Detiene de forma forzosa un sonido o música que el jugador esté oyendo.
- **Categorías:** `audio`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `sound` | Sonido a silenciar de forma forzosa. | `SOUND` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: stop_sound
    args:
      sound: SPEED
```
