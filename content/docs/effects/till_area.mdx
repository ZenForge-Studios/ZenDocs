# `till_area`

* **Categorías:** `farming, blocks` 
* **Identificador / Alias:** `till_area`

---

Ara la tierra en un radio de bloques simultáneamente con azadas.
- **Categorías:** `farming, blocks`
- **Requisitos de Trigger:** `till_soil`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `radius` | Radio de arado en bloques. | `INTEGER` | `2` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: till_area
    args:
      radius: 2
```
