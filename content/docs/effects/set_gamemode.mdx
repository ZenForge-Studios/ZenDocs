# `set_gamemode`

* **Categorías:** `player, server` 
* **Identificador / Alias:** `set_gamemode`

---

Cambia el modo de juego del jugador.
- **Categorías:** `player, server`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `gamemode` | Modo de juego (SURVIVAL, CREATIVE, ADVENTURE). | `GAMEMODE` | `SURVIVAL` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: set_gamemode
    args:
      gamemode: SPEED
```
