# `decay_blocks`

* **Categorías:** `world, blocks` 
* **Identificador / Alias:** `decay_blocks`

---

Convierte piedra o bloques sólidos en grava o arena derruida.
- **Categorías:** `world, blocks`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `radius` | Radio de derruido en bloques. | `INTEGER` | `2` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: decay_blocks
    args:
      radius: 2
```
