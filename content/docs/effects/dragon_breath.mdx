# `dragon_breath`

* **Categorías:** `combat, area` 
* **Identificador / Alias:** `dragon_breath`

---

Crea una nube persistente de aliento de dragón que inflige daño mágico.
- **Categorías:** `combat, area`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `duration` | Duración de la nube mágica en segundos. | `INTEGER` | `4` |
| `radius` | Radio de la nube. | `DECIMAL` | `3.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: dragon_breath
    args:
      duration: 2
      radius: 1.0
```
