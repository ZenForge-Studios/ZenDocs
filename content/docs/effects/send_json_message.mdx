# `send_json_message`

* **Categorías:** `messages, chat` 
* **Identificador / Alias:** `send_json_message`

---

Envía componentes Raw JSON avanzados con eventos de click y hover.
- **Categorías:** `messages, chat`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `json` | Componente Raw JSON con eventos click y hover. | `STRING` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: send_json_message
    args:
      json: SPEED
```
