# `disarm`

* **Categorías:** `combat, player` 
* **Identificador / Alias:** `disarm`

---

Obliga a la víctima a soltar el ítem que sostiene en su mano principal.
- **Categorías:** `combat, player`
- **Requisitos de Trigger:** `VICTIM`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `chance` | Probabilidad de desarmar al objetivo. | `EXPRESSION` | `15` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: disarm
    args:
      chance: 1.0
```
