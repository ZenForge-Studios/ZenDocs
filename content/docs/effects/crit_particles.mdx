# `crit_particles`

* **Categorías:** `visual, combat` 
* **Identificador / Alias:** `crit_particles`

---

Dispara ráfagas de partículas de impacto crítico.
- **Categorías:** `visual, combat`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Cantidad de chispas críticas. | `INTEGER` | `10` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: crit_particles
    args:
      amount: 2
```
