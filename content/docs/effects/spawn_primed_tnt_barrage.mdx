# `spawn_primed_tnt_barrage`

* **Categorías:** `world, combat` 
* **Identificador / Alias:** `spawn_primed_tnt_barrage`

---

Lanza un bombardeo de dinamitas en la zona objetivo.
- **Categorías:** `world, combat`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Cantidad de dinamitas. | `INTEGER` | `3` |
| `spread` | Dispersión. | `DECIMAL` | `2.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: spawn_primed_tnt_barrage
    args:
      amount: 2
      spread: 1.0
```
