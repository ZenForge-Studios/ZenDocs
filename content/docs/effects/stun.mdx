# `stun`

* **Categorías:** `combat, entity` 
* **Identificador / Alias:** `stun`

---

Inmoviliza a la criatura o jugador cancelando su velocidad de movimiento.
- **Categorías:** `combat, entity`
- **Requisitos de Trigger:** `VICTIM`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `duration` | Segundos de inmovilización. | `EXPRESSION` | `3` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: stun
    args:
      duration: 1.0
```
