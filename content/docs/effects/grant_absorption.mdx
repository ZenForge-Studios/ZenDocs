# `grant_absorption`

* **Categorías:** `potions, health` 
* **Identificador / Alias:** `grant_absorption`

---

Otorga corazones dorados de absorción temporal.
- **Categorías:** `potions, health`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Puntos de absorción concedidos (2 = 1 corazón dorado). | `EXPRESSION` | `4.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: grant_absorption
    args:
      amount: 1.0
```
