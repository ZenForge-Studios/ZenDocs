# `give_money`

* **Categorías:** `economy, player` 
* **Identificador / Alias:** `give_money`

---

Deposita dinero en la cuenta económica de Vault del jugador.
- **Categorías:** `economy, player`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Cantidad de dinero a otorgar (Vault). | `EXPRESSION` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: give_money
    args:
      amount: 1.0
```
