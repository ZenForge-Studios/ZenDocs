# `grant_glowing`

* **Categorías:** `potions, visual` 
* **Identificador / Alias:** `grant_glowing`

---

Resalta la silueta brillante de la entidad a través de paredes.
- **Categorías:** `potions, visual`
- **Requisitos de Trigger:** `VICTIM o PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `duration` | Segundos de silueta brillante. | `EXPRESSION` | `5` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: grant_glowing
    args:
      duration: 1.0
```
