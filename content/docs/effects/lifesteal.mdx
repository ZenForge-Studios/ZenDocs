# `lifesteal`

* **Categorías:** `combat, player` 
* **Identificador / Alias:** `lifesteal`

---

Drena un porcentaje del daño causado al oponente y lo transfiere como vida al atacante.
- **Categorías:** `combat, player`
- **Requisitos de Trigger:** `EVENT`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `percentage` | Porcentaje del daño causado transferido como vida (0.2 = 20%). | `EXPRESSION` | `0.2` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `LATE` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: lifesteal
    args:
      percentage: 1.0
```
