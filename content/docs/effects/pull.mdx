# `pull`

* **Categorías:** `combat, physics` 
* **Identificador / Alias:** `pull`

---

Atrae a la víctima hacia el jugador o viceversa.
- **Categorías:** `combat, physics`
- **Requisitos de Trigger:** `VICTIM o PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `strength` | Fuerza de atracción hacia el atacante. | `EXPRESSION` | `1.0` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: pull
    args:
      strength: 1.0
```
