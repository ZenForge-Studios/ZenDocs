# `blood_particles`

* **Categorías:** `visual, combat` 
* **Identificador / Alias:** `blood_particles`

---

Spawnea partículas de salpicadura de sangre en la criatura impactada.
- **Categorías:** `visual, combat`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Cantidad de partículas de sangre. | `INTEGER` | `15` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: blood_particles
    args:
      amount: 2
```
