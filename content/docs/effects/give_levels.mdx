Otorga niveles completos de experiencia.
- **Categorías:** `player, experience`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Niveles completos a otorgar. | `EXPRESSION` | `1` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: give_levels
    args:
      amount: 1.0
```
