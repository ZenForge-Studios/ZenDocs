# `repair_item`

* **Categorías:** `inventory, item` 
* **Identificador / Alias:** `repair_item`

---

Restaura puntos de durabilidad perdida al ítem utilizado o equipado.
- **Categorías:** `inventory, item`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Puntos de durabilidad a reparar. | `EXPRESSION` | `1` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: repair_item
    args:
      amount: 1.0
```
