# `grant_fire_resistance`

* **Categorías:** `potions, defense`

Otorga inmunidad total al fuego y la lava.
- **Categorías:** `potions, defense`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `duration` | Segundos de protección ignífuga. | `EXPRESSION` | `10` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: grant_fire_resistance
    args:
      duration: 1.0
```
