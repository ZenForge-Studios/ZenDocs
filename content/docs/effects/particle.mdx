# `particle`

- **Categoría:** efectos_visuales_y_rayos_cinemticos

- **Identificador / Alias:** `PARTICLE`
- **Descripción:** Genera una nube estática de partículas.

### Ejemplo de Configuración
```yaml
effects:
 - type: PARTICLE
    particle: CRIT
    count: 25
    speed: 0.2
```
