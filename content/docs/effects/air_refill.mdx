# `air_refill`

* **Categorías:** `player, utility` 
* **Identificador / Alias:** `air_refill`

---

Rellena la burbuja de aire del jugador bajo el agua.
- **Categorías:** `player, utility`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `amount` | Burbujas de aire a rellenar. | `INTEGER` | `300` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: air_refill
    args:
      amount: 2
```
