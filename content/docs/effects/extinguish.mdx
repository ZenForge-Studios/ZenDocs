# `extinguish`

* **Categorías:** `player, entity` 
* **Identificador / Alias:** `extinguish`

---

Apaga instantáneamente el fuego de la entidad.
- **Categorías:** `player, entity`
- **Requisitos de Trigger:** `PLAYER o VICTIM`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `target` | Objetivo a apagar (player o victim). | `STRING` | `player` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: extinguish
    args:
      target: SPEED
```
