# `convert_entity`

* **Categorías:** `entity, transform` 
* **Identificador / Alias:** `convert_entity`

---

Transforma la criatura golpeada en otra especie.
- **Categorías:** `entity, transform`
- **Requisitos de Trigger:** `VICTIM`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `to_type` | Especie resultante (CAT, SHEEP, etc.). | `ENTITY_TYPE` | `Obligatorio` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: convert_entity
    args:
      to_type: SPEED
```
