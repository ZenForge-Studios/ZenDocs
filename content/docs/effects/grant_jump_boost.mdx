# `grant_jump_boost`

* **Categorías:** `potions, movement` 
* **Identificador / Alias:** `grant_jump_boost`

---

Permite saltar bloques más altos y reduce daño por caída.
- **Categorías:** `potions, movement`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `duration` | Segundos de salto potenciado. | `EXPRESSION` | `6` |
| `amplifier` | Nivel de salto. | `EXPRESSION` | `1` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: grant_jump_boost
    args:
      duration: 1.0
      amplifier: 1.0
```
