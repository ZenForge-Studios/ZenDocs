# `spawn_minion`

* **Categorías:** `entity, minion` 
* **Identificador / Alias:** `spawn_minion`

---

Invoca un esbirro aliado que defiende al jugador durante un tiempo.
- **Categorías:** `entity, minion`
- **Requisitos de Trigger:** `LOCATION`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `type` | Tipo de entidad esbirro. | `ENTITY_TYPE` | `WOLF` |
| `duration` | Segundos de vida del esbirro. | `INTEGER` | `30` |
| `follow_owner` | Si persigue al dueño. | `BOOLEAN` | `true` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `true` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: spawn_minion
    args:
      type: SPEED
      duration: 2
      follow_owner: true
```
