# `silk_touch_spawner`

* **Categorías:** `mining, blocks` 
* **Identificador / Alias:** `silk_touch_spawner`

---

Permite obtener el spawner como ítem al minarlo con toque de seda.
- **Categorías:** `mining, blocks`
- **Requisitos de Trigger:** `mine_block`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `chance` | Probabilidad de dropear el spawner intacto. | `EXPRESSION` | `50` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: silk_touch_spawner
    args:
      chance: 1.0
```
