# `strip_wood_area`

* **Categorías:** `woodcutting, blocks` 
* **Identificador / Alias:** `strip_wood_area`

---

Descorteza todos los troncos en proximidad de un solo clic con hacha.
- **Categorías:** `woodcutting, blocks`
- **Requisitos de Trigger:** `strip_log`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `radius` | Radio de descortezado en bloques. | `INTEGER` | `2` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: strip_wood_area
    args:
      radius: 2
```
