# `add_cooldown`

* **Categorías:** `cooldown, utility` 
* **Identificador / Alias:** `add_cooldown`

---

Añade tiempo adicional de espera al cooldown de una habilidad.
- **Categorías:** `cooldown, utility`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `group` | Nombre del grupo de cooldown. | `STRING` | `Obligatorio` |
| `seconds` | Segundos sumados al cooldown. | `INTEGER` | `5` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: add_cooldown
    args:
      group: SPEED
      seconds: 2
```
