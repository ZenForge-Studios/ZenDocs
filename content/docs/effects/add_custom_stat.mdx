# `add_custom_stat`

* **Categorías:** `statistics, player` 
* **Identificador / Alias:** `add_custom_stat`

---

Incrementa una estadística interna del plugin para el jugador.
- **Categorías:** `statistics, player`
- **Requisitos de Trigger:** `PLAYER`

**Argumentos:**
| Key(s) | Descripción | Tipo | Default |
| :--- | :--- | :--- | :--- |
| `stat` | Nombre de la estadística personalizada. | `STRING` | `Obligatorio` |
| `amount` | Incremento numérico. | `INTEGER` | `1` |

**Comportamiento:**
| Propiedad | Valor |
| :--- | :--- |
| Run order | `NORMAL` |
| Supports delay | `false` |
| Reloads on reload | `true` |

**Ejemplo:**
```yaml
effects:
 - id: add_custom_stat
    args:
      stat: SPEED
      amount: 2
```
